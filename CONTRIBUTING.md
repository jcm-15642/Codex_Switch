# Contributing

## Local setup

Use Node.js 20 or later, then run:

```powershell
npm ci
npm test
```

Run `npm run package` before submitting a release-related change.

## Pull requests

- Keep API keys, `~/.codex` files, backups, screenshots, and local paths out of commits.
- Add or update tests for behavior changes.
- Keep changes focused and explain user-visible behavior in the pull request.
